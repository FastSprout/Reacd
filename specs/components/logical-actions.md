# Logical action arguments

ACTION-ARGS-001: Public zero-argument capabilities receive exactly zero arguments.
Trusted adapters explicitly invoke the capability rather than forwarding a native
React event or design-system eventDetails. Public callback types remain unchanged.
Button and User acceptance checks the exact runtime argument list on real activation.

Compatibility correction: apply the minimal adapter-only callback delta before larger
Element contracts. It adds no components, props, dependency or state kind.

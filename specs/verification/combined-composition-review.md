## Scope and observed regressions

Form now carries inherited disabled metadata and logical availability through
its content, including already-open portals. Submitting masks user interaction
without disabling canonical native form values; disabled omits those values.
Tabs propagates inherited logical activity to explicit and shared retained panels.
Inactive panels hide portals without changing host open intent or dropping state.

The unit red in form-portal-review-red.log recorded two unwanted callbacks carrying
'admin' after an open Form became disabled or submitting. The valid ordinary
production red in composition-form-baseline-browser-red2.log showed the Admin
option remaining visible after protection. The candidate Form/Tab corrections
fixed these and the physical native-ancestry proof, but the ten-case candidate
run still failed both retained-tab cases: Modal restored focus into an inactive
automatic tab trigger, reopening the stale tab. Modal now suppresses final focus
only while its ancestor scope is inactive. Ordinary close still restores focus.

TrustedFormBoundary probes the scoped client DOM before mounting a native form,
avoiding temporary nested markup. SSR has no physical host DOM to inspect: it
uses logical Form scope only. Trusted server integration must not place SSR Form
under an undeclared raw native form ancestor. This limitation is explicit;
client ancestry protection is not claimed as a proof of arbitrary server markup.

The catalog no longer re-exports runtime names through its type-only dependency
path. The graph acceptance includes type-only imports and facade re-exports,
rejects real cycles and accepts dependency diamonds. Time draft validity/focus
reuses the existing shared temporal algorithm and completion sentinel through
private re-exports, preserving declarations and accepted draft behavior.

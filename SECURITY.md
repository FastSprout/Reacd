# Security policy

Report suspected vulnerabilities for the affected package and version. Include a minimal
reproduction, the likely impact and a way to contact you. Remove credentials, personal
data and other secrets from reports and attachments.

Check the repository's [Security page][security] for private reporting. If GitHub offers
**Report a vulnerability**, use that form. If no private reporting option is available,
open an issue requesting a reporting contact without posting exploit details. Share
sensitive reproduction steps only after a private channel has been established.

[security]: https://github.com/FastSprout/Reacd/security
